# Nestora — client demo click-through (~12–15 min)

OTP for all logins: **`123456`**

## 1. Buyer journey (≈7 min)

1. **Home** — Nestora hero; switch Buy/Rent tabs; pick city; multi-select localities; Search.
2. **Search** — sidebar filters, chips, sort, grid ↔ list; toggle **Map**, pan to refresh; **Save search**.
3. Open a **Featured / Verified** card → gallery (photos / video / floor plan + lightbox).
4. Sticky card: **Contact** enquiry → **View phone** (login) → **Schedule site visit** (confirm screen).
5. Locality chart + nearby map; shortlist heart; Share.
6. **EMI widget** on detail → full `/tools/emi` + `/tools/loan-eligibility`.
7. Header → **Dashboard** — enquiries, visits, shortlist, saved searches. Bell shows alerts.

## 2. Seller journey (≈5 min)

8. Logout / login as **Owner** or **Agent**.
9. **Post property** — walk all 7 steps (drop map pin, upload photo, pick Gold plan) → fake checkout.
10. **Seller dashboard**
    - Overview charts & top listings  
    - Listings: Pause, **Promote** (Featured), **Verify** (upload mock doc)  
    - Leads: table ↔ kanban, notes, quick reply  
    - Site visits: calendar Accept / Decline / Reschedule  

## 3. Builder microsite (≈3 min)

11. Home or Search → **New Projects** → open e.g. **Aether Crest**.
12. Hero → configs → **unit grid** filters → price list → amenities → location map → gallery → RERA + construction timeline.
13. Sticky **Enquire** form; open **builder profile** for all their projects.

## Talking points

- All data & contacts are fictional; payments/OTP/docs are mocked for a real API later.
- Filters live in the URL — shareable search links.
- Original Nestora brand (not a clone of any live portal’s assets).
